# Operator runbook

Install dependencies explicitly with `npm ci` in `backend/` and `frontend/`. Review and apply the migrations through `backend/migrations/007_menu_source_objects.sql` using `DATABASE_URL=... ./scripts/migrate.sh`; startup never installs, seeds, migrates, kills ports, or starts PostgreSQL. Copy `.env.example`, set a unique 32+ character `JWT_SECRET`, keep experimental routes disabled, then run `./start.sh`.

The governed menu screen uses the authenticated user's ID as a private workspace by default. An administrator may grant a second existing account access to that workspace by inserting its user ID and the workspace ID into `menu_workflow_memberships`; do this through the controlled database change process. The second account can select the shared workspace in the screen. Menu creators cannot approve their own label or translation evidence. The approval transition derives reviewed evidence counts from database rows; caller supplied counts or publication receipts are ignored.

OCR output below 0.90 confidence or marked handwriting stays in correction review. All safety labels need supplier/restaurant evidence. The screen uploads original PDFs/images into tenant-scoped database storage with a server-computed SHA-256. Extractable PDF text is shown for manual correction. For stored images and image-only PDFs of at most five pages, the editor can explicitly run an on-server OCR candidate extractor. Install Tesseract and its language data plus Poppler's `pdftoppm` on the application host; configure `MENU_TESSERACT_PATH`, `MENU_PDFTOPPM_PATH`, and `MENU_OCR_LANGUAGE` if their defaults do not match. Each PDF page is rasterized at bounded size before OCR; sources longer than five pages need splitting or manual transcription. The extracted lines and mean word confidence remain unreviewed, and the editor must check every name, price, and label against the stored scan. If OCR is unavailable or finds no text, manual transcription remains available. The screen also accepts corrected menu JSON, location-specific item availability, and versioned evidence references. After independent review, an authorized operator can publish a `web` channel version with a checksum-matched stored original source to this app's public `/web-menu/:token` destination. That action records a delivered hosted-menu receipt, keeps the location URL stable across version changes, and records a rollback target; `0` means withdrawal if no earlier version exists. Rolling back restores the prior version or withdraws the public menu. Only approved labels and translations appear publicly. This hosted web menu is an app-owned destination; POS/KDS/marketplace execution still needs real credentials, sandbox fixtures, deletion/conflict tests, and operator approval.
